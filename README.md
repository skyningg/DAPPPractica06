En esta practica se realizó un crud de empleados en java con base de datos potgres, esta primera fase la práctica, se enfocó en poder realizar el backend de nuestro proyecto, cerrándolo enprática 6.
Agregando un administrador en nuestra base de datos con una contraseña encriptada para poder ingresar a los datos de empleados frozosamente con un usurio y contraseña.
En caso de entrar desde navegador se pediría autenticación.
